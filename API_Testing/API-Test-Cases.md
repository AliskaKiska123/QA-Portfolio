# Тест-кейсы API

**Проект:** QA Portfolio - API Testing  
**Тестируемый сервис:** DummyJSON  
**Базовый URL:** https://dummyjson.com  
**Тип тестирования:** API-тестирование  
**Инструменты:** Postman, Python, requests, pytest

## 1. Получение данных пользователя

### TC-API-001. Получение существующего пользователя

**Метод:** GET  
**Endpoint:** `/users/18`

**Предусловия:** API доступно.

**Шаги:**
1. Отправить GET-запрос на `/users/18`.
2. Проверить статус ответа.
3. Проверить содержимое JSON.

**Ожидаемый результат:**
- HTTP 200.
- В ответе присутствует пользователь с `id = 18`.
- `firstName` равен `Logan`.
- `role` равен `user`.

**Фактический результат:** соответствует ожидаемому.

**Статус:** Passed.

### TC-API-002. Получение несуществующего пользователя

**Метод:** GET  
**Endpoint:** `/users/{id}`

**Тестовые данные:** `9999`, `10000`, `-1`, `0`.

**Шаги:**
1. Отправить GET-запрос с каждым из указанных ID.
2. Проверить статус ответа.

**Ожидаемый результат:** HTTP 404 для каждого указанного ID.

**Фактический результат:** HTTP 404 во всех четырёх случаях.

**Статус:** Passed.

## 2. Авторизация

### TC-API-003. Успешная авторизация

**Метод:** POST  
**Endpoint:** `/auth/login`

**Тестовые данные:** действительные учётные данные тестового пользователя.

**Шаги:**
1. Отправить POST-запрос с username и password в JSON Body.
2. Проверить статус ответа.
3. Проверить данные пользователя.
4. Проверить наличие `accessToken`.

**Ожидаемый результат:**
- HTTP 200.
- В ответе присутствует username.
- В ответе присутствует accessToken.

**Фактический результат:** соответствует ожидаемому.

**Статус:** Passed.

### TC-API-004. Получение профиля с действительным токеном

**Метод:** GET  
**Endpoint:** `/auth/me`

**Предусловия:** получен действительный accessToken.

**Шаги:**
1. Передать токен в заголовке Authorization в формате Bearer.
2. Отправить GET-запрос.
3. Проверить статус и данные профиля.

**Ожидаемый результат:**
- HTTP 200.
- Username равен `logant`.
- Role равен `user`.

**Фактический результат:** соответствует ожидаемому.

**Статус:** Passed.

### TC-API-007. Проверка email и типов данных профиля

**Метод:** GET  
**Endpoint:** `/auth/me`

**Предусловия:** получен действительный accessToken.

**Шаги:**
1. Передать токен в Authorization.
2. Отправить GET-запрос.
3. Проверить наличие поля email.

**Ожидаемый результат:**
- HTTP 200.
- Email равен `logan.torres@x.dummyjson.com`.
- Поле `id` имеет тип integer.
