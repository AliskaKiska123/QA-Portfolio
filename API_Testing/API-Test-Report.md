# Отчёт о тестировании API

## 1. Общая информация

**Проект:** QA Portfolio - API Testing  
**Тестируемый сервис:** DummyJSON  
**Базовый URL:** https://dummyjson.com  
**Вид тестирования:** API-тестирование  
**Инструменты:** Postman, Python, requests, pytest

## 2. Объём тестирования

В ходе тестирования проверялись:

- Получение данных пользователя.
- Обработка запросов с несуществующими ID.
- Успешная авторизация.
- Получение профиля с действительным токеном.
- Обработка запросов без токена.
- Обработка запросов с недействительным токеном.
- Проверка структуры и типов данных ответа.

## 3. Результаты тестирования

| Показатель | Результат |
|---|---:|
| Всего автоматизированных запусков | 10 |
| Успешно пройдено | 10 |
| Не пройдено | 0 |
| Ошибок выполнения | 0 |

**Результат:** 100% успешных тестовых запусков.

## 4. Выявленные особенности

В ходе проверки установлено:

- API возвращает HTTP 200 при успешном получении данных.
- Для проверенных несуществующих ID возвращается HTTP 404.
- При успешной авторизации возвращается accessToken.
- Запрос профиля без токена возвращает HTTP 401.
- Запрос профиля с недействительным токеном возвращает HTTP 401.
- В ответе профиля присутствуют ожидаемые поля и типы данных.

## 5. Вывод

В рамках тестирования успешно проверены основные сценарии получения пользовательских данных и авторизации.

Все 10 автоматизированных тестовых запусков завершились успешно.

Критических несоответствий в рамках проверенных сценариев не обнаружено.

**Ограничения:** тестирование проводилось на демонстрационном API DummyJSON. Результаты не подтверждают корректность всех функций сервиса и не заменяют проверку реального API по утверждённой спецификации.
