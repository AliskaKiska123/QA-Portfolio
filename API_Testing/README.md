# API-тестирование

## О проекте

Учебный проект по тестированию REST API на примере сервиса [DummyJSON](https://dummyjson.com).

Цель проекта — закрепить навыки ручного и автоматизированного тестирования API, проверки ответов сервера и работы с авторизацией.

## Инструменты

- Postman - отправка запросов и проверка ответов API.
- Python - написание автоматизированных API-тестов.
- Pytest - запуск и организация тестов.
- Requests - отправка HTTP-запросов.
- Git и GitHub - хранение проекта.

## Что тестировалось

### Работа с пользователями
- Получение существующего пользователя.
- Получение пользователя с несуществующим ID.
- Проверка статус-кодов и данных ответа.

### Авторизация
- Успешная авторизация.
- Получение профиля с действительным токеном.
- Получение профиля без токена.
- Получение профиля с недействительным токеном.
- Проверка email и типов данных.

## Автоматизация

Написаны автоматизированные тесты на Python с использованием Pytest и Requests.

Реализованы:
- проверки статус-кодов HTTP;
- проверки содержимого JSON-ответов;
- проверки типов данных;
- параметризация тестов;
- фикстуры для получения токена авторизации.

## Результаты

- 10 автоматизированных проверок - PASSED.
- 0 FAILED.
- 0 ERROR.

В Postman настроены 7 запросов, включая автоматическое сохранение токена и 4 проверки ответа профиля.

## Структура проекта

- `API-Test-Cases.md` - тест-кейсы API.
- `API-Test-Report.md` - отчёт о тестировании.
- `Postman-Collection.json` - коллекция запросов Postman.
- `README.md` - описание проекта.

## Ограничения

DummyJSON - демонстрационный API. Результаты тестирования относятся к его текущему поведению и не являются проверкой промышленной системы.
