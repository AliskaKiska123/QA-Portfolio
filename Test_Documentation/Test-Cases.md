# Тест-кейсы SauceDemo

## TC-001 - Успешная авторизация

**Предусловия:**
1. Открыта страница авторизации SauceDemo.
2. Пользователь не авторизован.

**Тестовые данные:**
- **Username:** `standard_user`
- **Password:** `secret_sauce`

**Шаги выполнения:**
1. Ввести `standard_user` в поле **Username**.
2. Ввести `secret_sauce` в поле **Password**.
3. Нажать кнопку **Login**.

**Ожидаемый результат:**

Пользователь успешно авторизуется. Открывается страница каталога товаров.

**Фактический результат:**

Пользователь успешно авторизован. Открылась страница каталога товаров.

**Статус:** Пройден

Оба товара добавлены в корзину. Счётчик корзины показывает `2`. Названия и цены товаров отображаются корректно. Значение **Item total** составляет $57.98.

## TC-015 - Проверка формирования PDF заказа

**Предусловия:**
1. Пользователь авторизован.
2. Открыта страница каталога товаров.
3. В корзину добавлен товар **Sauce Labs Backpack**.

**Тестовые данные:**
- **Username:** `standard_user`
- **Товар:** Sauce Labs Backpack
- **Цена:** $29.99
- **First Name:** `Алиса`
- **Last Name:** `Сметанина`
- **Zip/Postal Code:** длинная последовательность цифр без пробелов.

**Шаги выполнения:**
1. Перейти в корзину.
2. Нажать кнопку **Checkout**.
3. Заполнить все обязательные поля тестовыми данными.
4. Нажать кнопку **Continue**.
5. Проверить информацию о заказе на странице **Overview**.
6. Нажать кнопку **Finish**.
7. На странице подтверждения заказа нажать **Generate PDF order**.
8. Открыть сформированный PDF-файл.
9. Проверить отображение имени, фамилии и почтового индекса.

**Ожидаемый результат:**

Заказ успешно оформлен. PDF-файл сформирован. Имя и фамилия корректно отображаются кириллическими символами. Введённое значение почтового индекса полностью отображается в документе и не выходит за его границы.

**Фактический результат:**

Заказ успешно оформлен, PDF-файл сформирован. Кириллические символы в имени и фамилии отображаются некорректно. Длинное числовое значение почтового индекса выходит за границы документа и обрезается.

**Статус:** Не пройден
