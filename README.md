# QA Portfolio - тестирование интернет-магазина

## О проекте

Учебный проект по ручному тестированию веб-приложения интернет-магазина [SauceDemo](https://www.saucedemo.com/).

Цель проекта - получить практический опыт тестирования веб-приложения, научиться составлять тестовую документацию, выявлять и описывать дефекты, а также оформлять результаты тестирования.

## Объект тестирования

**Приложение:** SauceDemo

В рамках проекта проверялись следующие функциональные возможности:

- Авторизация пользователей.
- Просмотр каталога товаров.
- Добавление и удаление товаров из корзины.
- Просмотр содержимого корзины.
- Оформление заказа.
- Расчёт стоимости товаров, налога и итоговой суммы.
- Завершение оформления заказа.
- Генерация PDF-документа с информацией о заказе.

## Результаты тестирования

В ходе проекта было составлено и выполнено 15 тест-кейсов.

- Всего тест-кейсов: 15.
- Пройдено: 12.
- Не пройдено: 3.
- Успешно пройдено: 80%.

Зарегистрировано 4 подтверждённых дефекта:

- **BUG-001:** поля оформления заказа принимают значения, состоящие только из пробелов.
- **BUG-002:** погрешность вычислений с плавающей точкой при расчёте суммы товаров.
- **BUG-003:** некорректное отображение кириллицы в PDF-документе.
- **BUG-004:** обрезание длинного числового почтового индекса в PDF-документе.

## Ограничения

- Тестирование проводилось вручную.
- Автоматизированное тестирование не выполнялось.
- API-тестирование и тестирование безопасности не входили в объём проекта.
- Полноценное нагрузочное и кроссбраузерное тестирование не проводилось.
